# Student Grade Calculator 

A Python program that accepts student marks, calculates the total and average, and assigns grades based on predefined grading criteria.

## Features
- Accepts marks for multiple subjects.
- Calculates total marks.
- Computes average marks.
- Assigns grades based on the average.
- Validates marks between 0 and 100.

## Grade Criteria

| Average | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

## Concepts Used
- Functions
- Lists
- For loops
- Conditional statements
- Built-in functions

## Technologies
- Python 3

## How to Run
```bash
python3 student_grade_calculator.py
```
